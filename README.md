# Saraswathi R — Portfolio

A responsive React portfolio built with HTML, CSS, and JavaScript using Vite.

## Run locally

1. Install Node.js (LTS) if it is not installed.
2. Open this project folder in VS Code.
3. Open the terminal in the project folder and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal (usually `http://localhost:5173`).

## Customize

- Edit profile text and project details in `src/App.jsx`.
- Update colors, spacing, and responsive styles in `src/App.css`.
- The portfolio currently showcases three projects: Online Course Management System, Employee Student Skill Gap Analyzer, and Weather Application.
- The To-Do List Application and the portfolio website itself are not listed as portfolio projects.
